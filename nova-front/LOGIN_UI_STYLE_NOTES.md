# ChatNova 登录页 / 全局 UI 风格总结

> 本文档用于团队后续页面开发统一视觉语言。**新页面必须严格遵循本规范。**

---

## 一、核心风格关键词

- 微信同款高级简约风
- 极简主义 + 大量留白
- 干净、克制、无多余装饰
- iOS / Android 融合的原生体验感
- App Store 级精致感

---

## 三、组件视觉规范

### 顶部品牌区

- 顶部留白 `180rpx`
- Logo：`128rpx × 128rpx`，圆角 `32rpx`，主色渐变，带色阴影
- 标题：`56rpx` 粗体 `#111`
- 副标题：`26rpx` `#666`，字间距 `1rpx`
- 整体居中排布

### 白色登录卡片

- 圆角 `32rpx`
- 内边距 `40rpx`
- 背景纯白，柔和阴影
- 与顶部距离：`56rpx ~ 72rpx`

### 输入框

- 高度 `92rpx`
- 圆角 `20rpx`
- 边框 `1px #EAEAEA`
- **focus 态**：绿色描边 + `0 0 0 4rpx rgba(7,193,96,0.12)` 光晕
- 左侧可放前缀（`+86`）/ 图标，用 `1px × 36rpx` 细分割线与内容隔开
- 密码框右侧眼睛图标支持明/暗切换

### 主按钮（立即登录）

- 高度 `92rpx`，胶囊圆角 `999rpx`
- 背景：`linear-gradient(135deg,#07C160,#10D876)`
- 文案 `32rpx` 白色 600 字重，字间距 `4rpx`
- 按压态：`transform: scale(0.98)` + 轻微降透明
- 加载态：文案切为"登录中..."，opacity 0.8

### 辅助入口（验证码登录 / 忘记密码）

- `26rpx` `#666`
- 左右两端分布

### 底部协议 & 注册

- 协议文本 `24rpx` `#666`
- 协议链接（《用户协议》《隐私政策》）绿色高亮
- 勾选态绿色、未勾选灰色
- "立即注册" 绿色高亮，稍加字重 500

## 四、交互规范

- 手机号正则 `^1\d{10}$`
- 密码不能为空
- 未勾选协议 → 阻止登录 + Toast
- 所有反馈统一 `uni.showToast`（`icon: 'none'`，duration 1.8s）
- 登录中：`uni.showLoading` + 按钮 loading 态 + 防重复点击
- 登录成功 → `uni.switchTab('/pages/home/index')`，失败 → `uni.reLaunch` 兜底
- 密码支持显示 / 隐藏切换（🙈 / 👁）

---

## 五、信息层级原则（关键）

> **高留白 + 强主按钮 + 弱化次操作**

- 主操作：大、亮、渐变、带阴影
- 次操作：小、灰、无背景
- 协议、提示：最小号字 + 次文字色
- 所有"跳转入口"类链接一律使用主色 `#07C160`

---

## 六、后续页面延续建议

- 注册 / 验证码登录 / 找回密码 / 绑定手机 → 沿用同一卡片 + 主按钮结构
- 聊天列表 → 卡片风格延续，头像使用同款渐变兜底
- 个人中心 → 分组列表，每组白色圆角卡片 + `32rpx` 圆角
- 所有页面背景统一 `#F7F8FA`，避免纯白通屏
- 字号节奏：`56 / 44 / 32 / 30 / 28 / 26 / 24`（rpx）
- 间距节奏：`8 / 12 / 16 / 24 / 30 / 40 / 56 / 72`（rpx）

---

## 七、代码约定

- Vue 3 `<script setup>` 语法
- 单位统一 `rpx`
- 样式统一 `<style scoped lang="scss">`
- 颜色禁止写死（除页面级特殊情况），优先引用 `uni.scss` 变量
- 接口统一通过 `@/utils/request` + `@/api/*` 模块调用
- 禁止在页面内直接写 `uni.request`
