## 三、核心工具模块

### 3.1 请求封装 (request.js)

**特性**:
- 自动携带 token
- 自动添加设备ID头
- 401 错误自动处理（清除登录态并跳转登录页）
- 统一错误提示

**使用示例**:
```javascript
import { http } from '@/utils/request';

// GET 请求
const res = await http.get('/user/users/me');

// POST 请求（需要登录）
const res = await http.post('/user/users/logout');

// POST 请求（不需要登录）
const res = await http.post('/user/users/login', data, { auth: false });
```

**代码位置**: [nova-front/src/utils/request.js](file:///d:/study/NovaChat/nova-front/src/utils/request.js)

### 3.2 认证工具 (auth.js)

**功能**:
- Token 管理（get/set/remove）
- 用户信息管理
- 登录状态检查
- 登录信息保存
- 需要登录才能访问的页面控制

**使用示例**:
```javascript
import { isLoggedIn, saveLoginInfo, clearAuth, requireAuth } from '@/utils/auth';

// 检查登录状态
if (isLoggedIn()) {
  // 已登录
}

// 保存登录信息
saveLoginInfo(token, userInfo);

// 清除登录信息（登出）
clearAuth();

// 需要登录才能访问
if (!requireAuth()) return;
```

**代码位置**: [nova-front/src/utils/auth.js](file:///d:/study/NovaChat/nova-front/src/utils/auth.js)

### 3.3 设备信息工具 (device.js)

**功能**:
- 生成并持久化设备ID
- 获取设备类型（Web/WeChat/iOS/Android）
- 获取设备详细信息

**使用示例**:
```javascript
import { getDeviceId, getDeviceType, getDeviceInfo } from '@/utils/device';

// 获取设备ID
const deviceId = getDeviceId();

// 获取设备类型
const deviceType = getDeviceType();

// 获取完整设备信息
const deviceInfo = getDeviceInfo();
```

**代码位置**: [nova-front/src/utils/device.js](file:///d:/study/NovaChat/nova-front/src/utils/device.js)

## 五、多端登录说明

### 5.1 设备ID机制

- 每个设备首次访问时生成唯一设备ID
- 设备ID持久化存储，同一设备保持相同ID
- 登录时传递设备ID，后端用于识别设备

### 5.2 登录模式

后端支持两种登录模式：

**单设备模式** (`single`):
- 新登录会踢掉旧会话
- 适用于高安全性场景

**多设备模式** (`multi`):
- 允许多设备同时登录
- 可配置最大设备数（默认3个）

### 5.3 Token 失效处理

当 Token 失效时（被登出、过期、被踢下线）：
1. 后端返回 401 或 1006 错误码
2. 前端拦截器自动清除登录态
3. 显示提示并跳转到登录页

## 七、运行测试

### 7.1 启动后端服务

```bash
# 1. 启动 Nacos
docker run -d --name nacos -p 8848:8848 nacos/nacos-server:v2.3.0

# 2. 启动 Redis
docker run -d --name redis -p 6379:6379 redis:7-alpine

# 3. 启动用户服务
cd nova-user
mvn spring-boot:run

# 4. 启动网关
cd nova-gateway
mvn spring-boot:run
```

### 7.2 启动前端

```bash
cd nova-front

# H5 开发模式
npm run dev:h5

# 微信小程序开发模式
npm run dev:mp-weixin
```

### 7.3 测试流程

1. **注册账号**: 访问注册页创建账号
2. **登录**: 使用账号密码登录，观察 token 和设备ID是否正确传递
3. **查看用户信息**: 进入"我的"页面，查看是否正确显示用户信息
4. **下拉刷新**: 下拉页面刷新用户信息
5. **登出**: 点击退出登录，验证是否清除登录态
6. **Token过期测试**: 在Redis中删除token，刷新页面验证是否跳转登录页

## 九、常见问题

### Q1: 登录后用户信息没有显示？

检查：
1. 登录接口是否返回了正确的 userId、username、nickname、avatar
2. 本地存储是否正确保存了 userInfo
3. "我的"页面是否正确调用了 getCurrentUser 接口

### Q2: 401 错误没有自动跳转登录页？

检查：
1. 后端是否正确返回了 401 状态码或 code=401/1006
2. request.js 中的 handleUnauthorized 函数是否被调用
3. 页面是否在请求时设置了 auth: false（跳过认证）

### Q3: 设备ID不一致？

检查：
1. 设备ID是否正确持久化到本地存储
2. 是否清除了本地存储导致重新生成设备ID
3. 不同平台的存储是否隔离（小程序和H5存储不互通）
