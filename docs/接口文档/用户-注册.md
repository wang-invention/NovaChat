# 用户注册

> 新用户注册账号。注册成功后 **不会** 直接返回 Token，需要前端再调用「用户登录」接口换取 Token。

## 基本信息

| 项目 | 内容 |
| :-- | :-- |
| 接口路径 | `/api/user/users/register` |
| 请求方法 | `POST` |
| 请求类型 | `application/json` |
| 是否鉴权 | 否（白名单） |
| 所属模块 | 用户模块（nova-user） |

---

## 请求参数

Body（JSON）：

| 字段 | 类型 | 必填 | 约束 | 说明 |
| :-- | :-- | :-- | :-- | :-- |
| `username` | string | 是 | 长度 4~32；必须以字母开头，仅允许 `a-zA-Z0-9_` | 登录账号，全局唯一 |
| `password` | string | 是 | 长度 8~32 | 明文密码，后端自行 BCrypt 加密 |
| `nickname` | string | 否 | 长度 ≤ 64 | 昵称，为空时后端会使用 `username` 兜底 |
| `phone` | string | 否 | 符合国内手机号：`^1[3-9]\d{9}$` | 手机号，如传了则必须唯一 |
| `email` | string | 否 | 合法邮箱格式 | 邮箱，如传了则必须唯一 |

### 请求示例

```http
POST /api/user/users/register HTTP/1.1
Host: localhost:8080
Content-Type: application/json
```

```json
{
  "username": "novauser01",
  "password": "Abcd1234!",
  "nickname": "小诺",
  "phone": "13800138000",
  "email": "nova@example.com"
}
```

### UniApp 调用示例

```js
uni.request({
  url: 'http://localhost:8080/api/user/users/register',
  method: 'POST',
  header: { 'Content-Type': 'application/json' },
  data: {
    username: 'novauser01',
    password: 'Abcd1234!',
    nickname: '小诺',
    phone: '13800138000',
    email: 'nova@example.com'
  },
  success: (res) => {
    const body = res.data
    if (body.code === 200) {
      uni.showToast({ title: '注册成功', icon: 'success' })
      uni.navigateTo({ url: '/pages/login/index' })
    } else {
      uni.showToast({ title: body.message || '注册失败', icon: 'none' })
    }
  }
})
```

---

## 响应参数

成功时 `data` 为 `UserVO`：

| 字段 | 类型 | 说明 |
| :-- | :-- | :-- |
| `id` | number(long) | 用户 ID |
| `username` | string | 登录账号 |
| `nickname` | string | 昵称 |
| `avatar` | string | 头像 URL（默认头像） |
| `phone` | string / null | 手机号 |
| `email` | string / null | 邮箱 |
| `gender` | number | 性别：0-未知，1-男，2-女 |
| `status` | number | 账号状态：1-正常，0-封禁 |
| `lastLoginTime` | string / null | 最近登录时间（ISO-8601） |
| `createTime` | string | 注册时间（ISO-8601） |

### 成功响应示例

```json
{
  "code": 200,
  "message": "注册成功",
  "data": {
    "id": 10086,
    "username": "novauser01",
    "nickname": "小诺",
    "avatar": "https://cdn.novachat.example.com/avatar/default.png",
    "phone": "13800138000",
    "email": "nova@example.com",
    "gender": 0,
    "status": 1,
    "lastLoginTime": null,
    "createTime": "2026-04-22T17:30:00"
  },
  "timestamp": 1714034400000
}
```

## 错误响应

| code | message 示例 | 触发场景 | 前端建议 |
| :-- | :-- | :-- | :-- |
| 400 | `username:用户名需以字母开头...` | 参数未通过校验 | Toast 显示 `message` |
| 1002 | `用户已存在` | `username` 已被注册 | Toast「用户名已被占用」 |
| 1002 | `手机号已注册` | `phone` 已被注册 | Toast「手机号已注册」 |
| 1002 | `邮箱已注册` | `email` 已被注册 | Toast「邮箱已注册」 |
| 500  | `系统繁忙，请稍后再试` | 未预期异常 | Toast + 稍后重试 |

### 错误响应示例

```json
{
  "code": 1002,
  "message": "用户已存在",
  "data": null,
  "timestamp": 1714034400000
}
```

```json
{
  "code": 400,
  "message": "password:密码长度需在 8~32 位",
  "data": null,
  "timestamp": 1714034400000
}
```

---

## 备注

1. 密码在传输层仅依赖 HTTPS 保障，**后端不会回显密码**。
2. 并发同名注册由后端唯一索引兜底，仍会返回 `1002`。
3. 注册接口在网关白名单中，不需要 `Authorization` 头。
