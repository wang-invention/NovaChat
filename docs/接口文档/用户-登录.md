# 用户登录

> 使用 **用户名 + 密码** 登录，成功后返回 JWT Token，前端后续所有受保护接口都需要在请求头携带
> `Authorization: Bearer {token}`。

> 当前仅支持账号密码登录。手机号验证码登录、三方登录将在后续版本追加新接口。

## 基本信息

| 项目 | 内容 |
| :-- | :-- |
| 接口路径 | `/api/user/users/login` |
| 请求方法 | `POST` |
| 请求类型 | `application/json` |
| 是否鉴权 | 否（白名单） |
| 所属模块 | 用户模块（nova-user） |

---

## 请求参数

Body（JSON）：

| 字段 | 类型 | 必填 | 约束 | 说明 |
| :-- | :-- | :-- | :-- | :-- |
| `username` | string | 是 | 非空 | 登录账号（即注册时的 `username`） |
| `password` | string | 是 | 非空 | 明文密码，后端使用 BCrypt 比对 |

> 前端如果在登录页使用「手机号 + 密码」，请把手机号当作 `username` 字段传入（当前后端仅以 `username` 列匹配账号；手机号登录将作为独立接口扩展）。

### 请求示例

```http
POST /api/user/users/login HTTP/1.1
Host: localhost:8080
Content-Type: application/json
```

```json
{
  "username": "novauser01",
  "password": "Abcd1234!"
}
```

### UniApp 调用示例

```js
uni.request({
  url: 'http://localhost:8080/api/user/users/login',
  method: 'POST',
  header: { 'Content-Type': 'application/json' },
  data: {
    username: 'novauser01',
    password: 'Abcd1234!'
  },
  success: (res) => {
    const body = res.data
    if (body.code === 200) {
      const { token, userId, username, nickname, avatar, expiresAt } = body.data
      uni.setStorageSync('token', token)
      uni.setStorageSync('userInfo', { userId, username, nickname, avatar, expiresAt })
      uni.switchTab({ url: '/pages/home/index' })
    } else {
      uni.showToast({ title: body.message || '登录失败', icon: 'none' })
    }
  }
})
```

## 响应参数

成功时 `data` 为 `LoginVO`：

| 字段 | 类型 | 说明 |
| :-- | :-- | :-- |
| `userId` | number(long) | 用户 ID |
| `username` | string | 登录账号 |
| `nickname` | string | 昵称 |
| `avatar` | string | 头像 URL |
| `token` | string | JWT Token，后续请求用于鉴权 |
| `expiresAt` | number(long) | Token 过期的绝对时间戳（毫秒） |

### 成功响应示例

```json
{
  "code": 200,
  "message": "登录成功",
  "data": {
    "userId": 10086,
    "username": "novauser01",
    "nickname": "小诺",
    "avatar": "https://cdn.novachat.example.com/avatar/default.png",
    "token": "eyJhbGciOiJIUzI1NiJ9.eyJzdWIiOiIxMDA4NiIsInVzZXJuYW1lIjoibm92YXVzZXIwMSJ9.xxx",
    "expiresAt": 1714639200000
  },
  "timestamp": 1714034400000
}
```

## 错误响应

| code | message 示例 | 触发场景 | 前端建议 |
| :-- | :-- | :-- | :-- |
| 400 | `username:用户名不能为空` | 参数未通过校验 | Toast 显示 `message` |
| 1001 | `用户不存在` | `username` 不存在 | Toast「账号或密码错误」（对外统一口径） |
| 1003 | `账号或密码错误` | 密码比对失败 | Toast 显示 `message` |
| 403  | `账号已被封禁` | 账号状态被设为 0 | Toast「账号已被封禁，请联系客服」 |
| 500  | `系统繁忙，请稍后再试` | 未预期异常 | Toast + 稍后重试 |

### 错误响应示例

```json
{
  "code": 1003,
  "message": "账号或密码错误",
  "data": null,
  "timestamp": 1714034400000
}
```

```json
{
  "code": 403,
  "message": "账号已被封禁",
  "data": null,
  "timestamp": 1714034400000
}
```

## Token 使用说明

1. 登录成功后持久化 Token：
   ```js
   uni.setStorageSync('token', data.token)
   ```
2. 后续所有受保护接口必须携带：
   ```
   Authorization: Bearer {token}
   ```
3. Token 默认有效期 **7 天**（`604800` 秒），可用 `expiresAt` 字段判定是否即将过期。
4. 网关对 Token 的校验结果：
   - 缺失：返回 `401`，`message: "缺少 Token"`
   - 无效：返回 `1004`，`message: "Token 无效"`
   - 过期：返回 `1005`，`message: "Token 已过期"`

### 401 统一处理示例

```js
// 在 request 封装里
if ([401, 1004, 1005].includes(res.data.code)) {
  uni.removeStorageSync('token')
  uni.removeStorageSync('userInfo')
  uni.reLaunch({ url: '/pages/login/index' })
}
```

---

## 备注

1. 为避免枚举账号，后端对「用户不存在」与「密码错误」的返回码会拉开（`1001` vs `1003`），
   前端建议统一展示「账号或密码错误」。
2. 登录会更新最近登录时间与 IP，该操作失败不会影响登录主流程。
3. 登出当前仅需前端清空本地 Token；服务端不做黑名单维护（后续版本再加）。
